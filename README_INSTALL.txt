WINDHAWK Centric Divinity Selection System - PWA App Package

What this is:
- This is your Divinity selector converted into an installable Progressive Web App package.
- It still saves data locally in your browser/device. Use Export JSON regularly for backup.

Files:
- index.html = main app file for web hosting / PWA install
- manifest.webmanifest = app name/icon/install settings
- sw.js = offline cache worker for hosted PWA mode
- icons/ = app icons
- WINDHAWK_Divinity_System_v28.html = direct standalone HTML copy

For personal use on PC without publishing:
1. Open WINDHAWK_Divinity_System_v28.html or index.html in Chrome/Edge.
2. Create your account.
3. Use Export JSON inside the app for backup.

To install like an app on Windows/Android/iPhone:
1. Upload this whole folder to a free HTTPS host such as GitHub Pages, Netlify, Cloudflare Pages, or Vercel.
2. Open the website link in Chrome/Edge/Safari.
3. Choose Install App / Add to Home Screen from the browser menu.

Important:
- PWA install/offline mode requires HTTPS or localhost. Opening by file:// works as a normal HTML app but may not show the Install button.
- Login/signup is local only and not a real online database account.
- Data is per browser/device unless you export/import JSON.
